# Plant Leaf Disease Detection Using VGG16

## Overview

This project uses Deep Learning and Transfer Learning (VGG16) to detect plant leaf diseases from images.

## Features

* Plant disease classification
* Transfer Learning using VGG16
* Data augmentation
* Model evaluation
* Grad-CAM visualization

## Technologies Used

* Python
* TensorFlow
* Keras
* OpenCV
* NumPy
* Matplotlib
* Google Colab

## Dataset

New Plant Diseases Dataset (Kaggle)

## Results

The model successfully classifies healthy and diseased leaves and provides visual explanations using Grad-CAM heatmaps.
